# AI Hostel Complaint Management System 🚀

## 📌 Project Overview

The AI Hostel Complaint Management System is a full-stack AI-powered platform designed to streamline hostel complaint handling and analytics.

The system allows students to submit complaints, classifies them using Machine Learning, stores complaint data, and visualizes insights through an interactive analytics dashboard.

This project demonstrates practical implementation of:

* Full-stack development
* REST APIs
* Machine Learning integration
* Cloud deployment
* Analytics dashboards
* AI workflow architecture

# 🚀 Installation & Setup

## Clone Repository

```bash
git clone https://github.com/Anantaag/AI_Hostel_Complaint_System.git
```

## Navigate to Project

```bash
cd AI_Hostel_Complaint_System
```

## Create Virtual Environment

```bash
python -m venv venv
```

## Activate Environment

### Windows

```bash
venv\Scripts\activate
```

### Linux / Mac

```bash
source venv/bin/activate
```

## Install Dependencies

```bash
pip install -r requirements.txt
```

## Run Backend

```bash
uvicorn backend.main:app --reload
```

## Run Dashboard

```bash
streamlit run frontend/dashboard.py
```
